chmod, a command used to change file and directory permissions on linux. 

Ex: 

chmod 644 - sets file permissions (using octal notation) so that the owner can read and write,
 while the group and everyone else can only read
permissions string: -rw-r--r--

chmod 755 - sets file permissions (using octal notation) so that the owner can have full read, write, and execute
permissions, while restricting group and all pthers to read and execute.
permissions string: rwxr-xr-x
